# Task 2: Data Visualization Using Python

## 1. Problem Statement

The objective of this task is to visualize data using different types of charts to identify patterns, compare features, and understand relationships between variables. The visualizations help present data clearly and extract meaningful insights.

## 2. Dataset Details

- **Dataset Name:** Iris Dataset
- **Source:** Seaborn Built-in Dataset
- **Number of Records:** 150
- **Number of Columns:** 5

The Iris dataset contains measurements of three flower species: Setosa, Versicolor, and Virginica.

### Dataset Features

| Column Name | Description |
|---|---|
| sepal_length | Length of the sepal |
| sepal_width | Width of the sepal |
| petal_length | Length of the petal |
| petal_width | Width of the petal |
| species | Species of the iris flower |

## 3. Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 4. Approach

The following steps were performed:

1. **Load Dataset:** Loaded the Iris dataset using Seaborn and Pandas.
2. **Inspect Data:** Examined the dataset structure and displayed the first few records.
3. **Bar Chart:** Created a bar chart to compare the average sepal length across the three species.
4. **Histogram:** Created a histogram to understand the distribution and frequency of sepal length.
5. **Scatter Plot:** Visualized the relationship between sepal length and petal length, using different colors for each species.
6. **Feature Comparison:** Calculated the average sepal and petal measurements for each species.

## 5. Visualizations Created

- **Bar Chart:** Compares average sepal length across flower species.
- **Histogram:** Shows the distribution of sepal length.
- **Scatter Plot:** Displays the relationship between sepal length and petal length.
- **Feature Comparison:** Compares average measurements across Setosa, Versicolor, and Virginica.

## 6. Results and Observations

- Setosa generally has smaller petal measurements than the other species.
- Virginica generally has larger petal measurements.
- Versicolor typically has intermediate petal measurements.
- Sepal length and petal length show an overall positive relationship.
- Petal measurements are useful for distinguishing between the three iris species.

## 7. Conclusion

This task demonstrates the importance of data visualization in data analysis. Using Python libraries, different charts were created to identify patterns, compare flower species, and understand relationships between features. The visualizations helped convert raw data into meaningful and understandable information.
